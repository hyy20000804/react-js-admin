# React-admin-vite

本项目使用前端新型构建工具 vite ， 更换了以往的 webpack。

开箱即用，使其开发效率提高，编译速度更快，减少复杂配置。

在正式启动项目前，请检查本地环境版本。如若启动失败，请升级 node。

react-admin-vite 适用于后台管理 web 项目的二次开发。让开发人员快速搭建后台管理项目。
